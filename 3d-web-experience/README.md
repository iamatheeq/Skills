# 3D Web Experience Skill

## How to use
Select **3D Web Experience** when you want to build, modify, review, or optimize interactive 3D, animation, or cinematic features.

## Use cases
- Three.js / React Three Fiber scenes
- 3D hero sections
- GLB/glTF models
- cinematic camera movement
- scroll-driven 3D
- GSAP animation
- post-processing
- physics
- responsive 3D
- performance and accessibility

## Select another skill when
- choosing technologies → **Technology Guide**
- defining fonts/type → **Typography System**
- defining colors/theme modes → **Theme System**
