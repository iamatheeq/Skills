# Typography System Skill

## How to use
Select **Typography System** when you want to define, select, apply, or review typography. If no approved font exists, the skill asks you to select/approve one.

## Use cases
- font selection
- type scales
- responsive typography
- desktop/tablet/mobile web
- iOS/Android/native semantic mapping
- Windows/macOS/Linux considerations
- localization
- accessibility/text scaling
- variable fonts
- Tailwind CSS v4+ typography tokens
