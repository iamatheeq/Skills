# Technology Guide Skill

## How to use
Select **Technology Guide** when you want to decide or compare technologies before implementation.

## Use cases
- Three.js vs Babylon.js
- WebGL vs WebGPU
- R3F decisions
- animation-library selection
- open-source/license evaluation
- long-term maintainability
- GLB/glTF workflow
- vendor-lock-in analysis
- architecture/dependency decisions

## Select another skill when
You want actual 3D implementation → **3D Web Experience**.
