# Theme System Skill

## How to use
Select **Theme System** when you want to define, select, apply, or review colors and visual theme behavior. If undefined, the skill asks you to choose:
- dark only
- light only
- system only
- both light and dark
- all/advanced modes

It also asks for/helps select the color palette.

## Use cases
- brand colors
- light/dark/system themes
- semantic color tokens
- Tailwind CSS v4+
- component states
- contrast/accessibility
- 3D visual-theme harmony
